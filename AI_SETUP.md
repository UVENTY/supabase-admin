# Настройка AI Assistant

## Использование Groq API (рекомендуется)

Groq предоставляет бесплатный и очень быстрый доступ к AI моделям.

### Шаги настройки:

1. **Зарегистрируйтесь на Groq:**
   - Перейдите на https://console.groq.com/
   - Создайте бесплатный аккаунт

2. **Получите API ключ:**
   - Войдите в консоль Groq
   - Перейдите в раздел "API Keys"
   - Создайте новый API ключ
   - Скопируйте ключ

3. **Добавьте ключ в проект:**

   **Вариант 1: Через переменные окружения (рекомендуется)**
   
   Создайте файл `.env` в корне проекта `tickets-admin/`:
   ```
   REACT_APP_GROQ_API_KEY=ваш_api_ключ_здесь
   ```
   
   **Вариант 2: Временно в коде (только для тестирования)**
   
   Откройте `tickets-admin/src/api/ai.js` и замените:
   ```javascript
   const GROQ_API_KEY = process.env.REACT_APP_GROQ_API_KEY || ''
   ```
   на:
   ```javascript
   const GROQ_API_KEY = process.env.REACT_APP_GROQ_API_KEY || 'ваш_api_ключ_здесь'
   ```
   
   ⚠️ **Внимание:** Не коммитьте API ключ в репозиторий!

4. **Перезапустите приложение:**
   ```bash
   npm start
   ```

## Альтернативные варианты

### Hugging Face API
В файле `tickets-admin/src/api/ai.js` есть функция `sendMessageToHuggingFace()`, которую можно использовать как альтернативу. Некоторые модели работают без API ключа.

### Google Gemini
Можно использовать Google Gemini API (также есть бесплатный tier):
- Зарегистрируйтесь на https://makersuite.google.com/app/apikey
- Получите API ключ
- Адаптируйте код в `ai.js` для использования Gemini API

## Преимущества Groq:
- ✅ Полностью бесплатный
- ✅ Очень быстрый (низкая задержка)
- ✅ Хорошее качество ответов
- ✅ Простая настройка
